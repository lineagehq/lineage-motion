# Historical goal records

The directories here preserve prior goal decisions and evidence. They are not
the default workflow, templates for new tasks, or standing instructions for an
agent that happens to read them.

Use `docs/agent-workflow.md` for routine development. Add or update a goal board
only when the user explicitly asks to create, resume, or operate that named
goal. Historical receipt cleanup is handled separately so old evidence is not
silently rewritten during unrelated work.
